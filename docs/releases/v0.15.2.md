## Srpski

### Bezbednost
- Novija verzija Electron-a (44.9.2) sa bezbednosnim zakrpama za Chromium, deo koji pušta video i prikazuje slike.
- Dodatni programi (mpv, ffmpeg, uosc, ani-cli, yt-dlp, Git (bash)) se posle preuzimanja proveravaju prema SHA-256 otisku koji objavljuje GitHub. Ako se ne poklapa, ništa se ne instalira i stara verzija ostaje.
- Arhive se raspakuju strožim pravilima: odbijaju se prečice (symlink-ovi), putanje van foldera i sumnjivi nazivi. Ako ažuriranje ne uspe, prethodna verzija programa ostaje netaknuta.

### Poboljšanja
- Oznake „filler” i „recap” sada stižu iz dva izvora i spajaju se: potpunije su, rade i kad jedan izvor ne radi, a za seriju koju prvi put otvaraš prve oznake se pojave brže.
- „Raspored”: na dan kad se menja računanje vremena stoji kratka napomena, da redosled vremena (npr. 02:30 pa 02:00) ne zbuni.
- „Raspored”: posle uspešnog „Pokušaj ponovo” fokus prelazi na naslov stranice, umesto da se izgubi.

## English

### Security
- Newer Electron (44.9.2) with security fixes for Chromium, the part that plays video and shows images.
- Extra tools (mpv, ffmpeg, uosc, ani-cli, yt-dlp, Git (bash)) are now checked against the SHA-256 fingerprint GitHub publishes after download. If it does not match, nothing is installed and the old version stays.
- Archives are extracted with stricter rules: shortcuts (symlinks), paths outside the folder and suspicious names are refused. If an update fails, the previous version of the tool stays untouched.

### Improvements
- "Filler" and "recap" marks now come from two sources that are merged: more complete, still working when one source is down, and the first marks appear faster for a series you open for the first time.
- "Schedule": on the day the clocks change a short note explains it, so the order of times (e.g. 02:30 then 02:00) is not confusing.
- "Schedule": after a successful "Try again" focus moves to the page heading instead of getting lost.
