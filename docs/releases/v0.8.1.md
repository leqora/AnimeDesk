## Srpski

### Ispravke
- Zatvaranje prozora u tray dok je preko celog ekrana više ne gasi režim celog ekrana; kad ponovo otvoriš prozor, vraća se na ceo ekran.
- Pre obaveštenja o novoj epizodi aplikacija još jednom proverava raspored emitovanja na AniList-u, pa odložena epizoda više ne izaziva lažno „Nova epizoda”. Bez interneta se i dalje najavljuje na osnovu onoga što aplikacija već zna.
- Panel obaveštenja (zvonce) se zatvara kad počne reprodukcija, pa više ne prekriva plejer.
- Ponovno pokretanje AnimeDesk-a dok se još pokreće sada prikaže prozor čim bude spreman.

## English

### Fixes
- Closing the window to the tray while in fullscreen no longer turns fullscreen off; reopening the window returns to fullscreen.
- Before announcing a new episode, the app double-checks the airing schedule with AniList, so a delayed episode no longer triggers a false "New episode". When offline, it still announces based on what it already knows.
- The notifications panel (bell) closes when playback starts, so it no longer covers the player.
- Starting AnimeDesk again while it is still starting up now shows the window as soon as it is ready.
