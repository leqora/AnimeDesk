# v0.15.1 „Raspored — doterivanje” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sedam sitnica stranice „Raspored”: podrazumevani dan, rok i zaustavljanje preuzimanja postera, test odbijenog preuzimanja, čitljiv onemogućen red, „Pokušaj ponovo” sa povratnom informacijom, stalan redosled.

**Architecture:** Zadatak 1 = glavni proces (`anilist.poster` rok, servis rasporeda: preskakanje posle `stop`/`forget`, `gen` u ključu, `retryAt`). Zadatak 2 = deljena pravila + renderer (`groupDay` collator, izveden podrazumevani dan, dugme sa `aria-disabled`/odbrojavanjem, CSS, i18n). Fajlovi se ne preklapaju → zadaci 1 i 2 idu paralelno. Zadatak 3 (verzija, beleške, STATUS) radi kontrolor.

**Tech Stack:** Electron, React 18, vitest + @testing-library/react (jsdom), Node `fetch`.

**Spec:** `docs/superpowers/specs/2026-10-20-v0.15.1-schedule-polish-design.md` (normativno; tačke se navode kao „spec N”).
