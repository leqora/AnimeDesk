# v0.20.0 „Mini plejer” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tokom epizode gornja traka (i novo dugme) smanjuje istu epizodu u plutajući mini plejer u uglu (prevlačenje, lepljenje za ugao, klik vraća pun prikaz), Pretraga radi dok mini svira; plus četiri sitnice (B1–B4).

**Architecture:** Isti `PlayerView` ostaje montiran i dobija prop `mini` (CSS `player--mini`, skrivene kontrole, mala traka sa tri dugmeta, prevlačenje). `App` drži `mini` i ugao, a sve što je danas zavisilo od `player`/`reconnecting` kao „sloj preko stranice” gleda samo pun plejer. Položaj mini plejera je čista funkcija (`miniLayout.js`). `SearchPage` razdvaja sesiju liste od sesije koja svira. Glavni proces dobija jednu izmenu: pre mpv-a zaustavlja ugrađeno puštanje.

**Tech Stack:** Electron 45, React 19, Vitest + Testing Library (jsdom), lucide-react ikone.

**Spec:** `docs/superpowers/specs/2026-10-29-v0.20.0-mini-player-design.md` (odeljak C ima prednost nad A/B).
