# v0.16.3 „Održavanje: Electron 45 + sitnice” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move to Electron 45 with async `safeStorage` (sync API is removed in Electron 46), make the external-mpv bar opaque, and give the Watchlist toolbar a data-independent one-row layout.

**Architecture:** The `crypt` adapter in `src/main/index.js` becomes Promise-based; `createAniListAuth` loads asynchronously behind a `ready` promise that `main()` awaits before anything reads the token, and all disk writes go through one serialized queue guarded by `generation`. CSS-only changes for the bar and the toolbar.

**Tech Stack:** Electron 45, React 19, Vitest, electron-vite, Playwright `_electron`.

**Spec:** `docs/superpowers/specs/2026-10-26-v0.16.3-maintenance-design.md`

## Review Focus

1. `disconnect()` while a `connect()` is between `await crypt.encrypt` and the write → no file on disk afterwards, status `none`.
2. `markExpired()` with slow encryption followed by a new `connect()` → the disk holds the new account (not the expired old one), and a restart loads the new account.
3. Corrupt/undecryptable token file (async `decrypt` rejects) → `ready` resolves, status `none`, file left in place.
4. `isAsyncEncryptionAvailable()` resolves `false` → `connect` returns `{ ok: false, error: 'unavailable' }`, nothing written; load leaves status `none`.
5. Watchlist with no genre data (select absent) and with the longest genre selected → toolbar height is the same on first and repeat entry at 1200×800.

Items 1–4 are tests in Task 1; item 5 is measured in the controller's manual check (Task 3).
