# v0.14.0 Preporuke — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home gets a "Preporuke za tebe" rail built from AniList community recommendations of series the user liked (falling back to "Popularno sada" = AniList trending), and the series detail gets a "Slično" section — never later parts, side stories, 18+ or plot text.

**Architecture:** Pure rules in new `src/shared/recommendations.js` (Appendix A normative, checked on the 502-case fixture). `anilist.js` gets `recommendations(ids)`/`trending()` that reduce AniList media to cache items. New main service `src/main/recommendations.js` mirrors `src/main/sequels.js` (cache file, timers, posters, hide/unhide, change event) plus `forSeries(id)`. Renderer: `pendingSearch` lifted to `App`, new `RecommendationCard`, rail on `HomePage`, "Slično" in `AnimeDetail`.

**Tech Stack:** Electron main (ESM `.js`, package NOT `"type": "module"`), React renderer, vitest (+ `renderUi`/`makeFakeApi` from `tests/unit/ui/helpers.jsx`).

**Spec:** `docs/superpowers/specs/2026-10-20-v0.14.0-recommendations-design.md` (points 1…25 referenced below, Appendix A). Read it.

## Global Constraints

- Appendix A is normative: `eligible()` must equal `eligible` for all 502 cases of `tests/fixtures/recommendations.cases.json` (do not edit the fixture). Case-insensitive regexes: `\b(season|part|cour)\s*([2-9]|\d{2,})\b`, `\b\d+(nd|rd|th)\s+season\b`, `\b(2nd|3rd)\s+stage\b`; case-sensitive: `\bII\b`, `\bPV\b`. `RULES_VERSION = 1`.
- Formats allowed: `TV, TV_SHORT, MOVIE, OVA, ONA`; statuses `FINISHED, RELEASING`.
- Seed weights: rating 8–10 → 3, 7 → 2, ≤6 → 0; no rating: completed → 2, watching → 1, else 0. Max 50 seeds. Score = Σ weight × (10 − rank). Max 20 on the rail, max 8 in "Slično", max 3 genres.
- TTLs: per seed 7 days (`604_800_000`), trending 24 h; failure pause 1 h; first run +120 s; debounce 30 s; daily timer; "Slično" poster timeout 8 s; posters kept for shown + first 20 hidden.
- Ids from the AniList title cache only when `match === 'exact'`; a `close` match is never a seed, never an exclusion id source, never a "Slično" id.
- No spoilers: no description/tags/characters/score/episode data anywhere on these surfaces. Nothing here goes through or around `seriesEpisodes.js` (no episode data).
- Copy (sr / en): `recommendations.titlePersonal` „Preporuke za tebe” / „Recommended for you”; `titleTrending` „Popularno sada” / „Popular now”; `hint` „Oceni seriju sa 7 ili više ili je završi da dobiješ preporuke za tebe.” / „Rate a series 7 or higher, or finish one, to get recommendations for you.”; `because` „Zbog: {title}” / „Because of: {title}”; `hide` „Ne preporučuj {title}” / „Don't recommend {title}”; `hidden` „Sakriveno: {title}” / „Hidden: {title}”; `open` „Potraži {title}” / „Search {title}”; `similar` „Slično” / „Similar”.
- Every commit ends with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never `git add -f`; never commit `.superpowers/`. Shared rules for implementers: `.superpowers/sdd/v0.14.0/implementer-instructions.md`.
- TDD; existing tests must not be weakened. Many files are CRLF — prefer Edit.

## Review Focus

1. A library entry linked only through an exact cached title id (no `aniListId`), in any status, never shows up as a recommendation (rail, trending or "Slično") — test in Task 1 (`libraryIds`) and Task 3 (`list`/`forSeries`).
2. Hint flips with identical items (first seed added, personal list still empty) → change event fires — test in Task 3.
3. "Slično" after a manual AniList pick: old list cleared at once, a late answer for the old id ignored — test in Task 6.
4. AniList down at start / during "Slično": rail keeps cached items, detail shows nothing, no 1 h pause caused by `forSeries` — tests in Task 3.
5. A recommendation that is also in the missed-sequels rail appears only once — test in Task 5.
