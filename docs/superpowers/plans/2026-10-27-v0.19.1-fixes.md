# v0.19.1 Popravke posle redizajna — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plejer više nije ispod gornje trake; traka se tokom epizode pojavljuje sa kontrolama i radi (klik zatvara epizodu i vodi na izabrano); „Nazad” vraća odakle je epizoda puštena; grupa epizoda se pamti; sitnice iz 0.19.0.

**Architecture:** Slojevi postaju CSS tokeni u `:root`. `inert` se sa `.app-shell` premešta na `main` (sadržaj), a `TopBar` dobija sopstveno `inert` + skrivanje kad je plejer otvoren i kontrole miruju / pun ekran / „ponovno povezivanje”. `PlayerView` javlja `idle` u `App` i prima `holdControls` i `closeRequest`. Poreklo gledanja je ref u `App`; povratak preko `nav.back()` ili `nav.navigate()`.

**Tech Stack:** Electron 45, React, Vitest + Testing Library (`renderUi`, `makeFakeApi` iz `tests/unit/ui/helpers.jsx`), CSS u `src/renderer/styles.css`.

**Spec:** `docs/superpowers/specs/2026-10-27-v0.19.1-fixes-design.md` (tačke 1–21 + „Pozivi graditelja”). Implementer čita spec i ovaj plan.
