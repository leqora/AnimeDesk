# v0.16.2 „Spoljni mpv: traka i Zaustavi” + bedž „N novih” — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While an app-launched external mpv plays, show a sticky bar „Pušta se u mpv-u: {serija} · EP {N}” with „Zaustavi” that quits mpv like a manual close; and stop showing „N novih” for a watching series with nothing watched.

**Architecture:** `playerMonitor.play` gains an `onStart({ quit })` hook (quit over the mpv IPC socket, `child.kill()` fallback). `watchService.runPlayer`'s `mpv()` wrapper keeps a map of running external players and notifies the renderer (`EVENTS.externalPlayer`); IPC exposes read/stop. A new `ExternalPlayerBar` sits at the top of `main.content`. The badge fix is a one-rule change in `shared/airing.js`.

**Tech Stack:** Electron main (Node), React renderer, vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-26-v0.16.2-mpv-bar-design.md` (read it first; it is in Serbian).

## Review Focus

1. „Zaustavi” clicked before the IPC pipe connects (mpv still starting) → the process must still end (kill), the bar must clear. (Task 2 test.)
2. mpv ignores `quit` (hung) → killed after 5 s; a second click does not stack timers. (Task 2 test.)
3. Stop after the watched threshold → episode recorded as watched and position saved exactly as a manual close; stop does NOT go through `cancel`. (Task 3 test.)
4. Two mpv players at once → bar shows the newest; stopping it reveals the older; stopping an unknown/finished id is a no-op. (Task 3 test.)
5. Bar disappears while focused → focus to `main.content`, never `body`; renderer mounted while mpv already plays → bar shown from `state()`. (Task 4 tests.)
