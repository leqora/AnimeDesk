# v0.7.3 UI infrastruktura — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shared `Modal`, a toast queue with “Undo” (series removal + episode mark), navigation history with scroll memory, and an AniList info cache in the renderer plus request dedup in main.

**Architecture:** Pure logic first (`history.js`, `toastQueue.js`, `infoCache.js`, main `restore`), then React wiring (`Modal`, `ToastProvider`, `useNavigation`/`useRouteState`, `useAniListInfo`). `App.jsx` owns the history and the toast provider; pages receive callbacks.

**Tech Stack:** Electron, React 18, vitest + @testing-library/react (jsdom), no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-16-v0.7.3-ui-infra-design.md` — read it before your task; section numbers below (§) refer to it.

## Global Constraints

- Every commit ends with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (project rule; it overrides any session default naming another model). Git identity is already set in the repo.
- TDD: failing test first. Unit tests in `tests/unit/`, UI tests in `tests/unit/ui/` using `renderUi` / `makeFakeApi` from `tests/unit/ui/helpers.jsx`.

- No hex colors outside `:root` in `styles.css` (`styles.test.js`); use existing tokens.
- No spoilers: new surfaces use only the series title and an episode **number**. No episode title/thumbnail/description, no new `episodes.forSeries` calls (`src/main/seriesEpisodes.js` is the only place that decides episode data).

- Many files are CRLF — prefer the Edit tool over sed/scripted rewrites.
- Run the full suite with `npm test` (vitest may print “Timeout waiting for worker” on the first run — just rerun).

## Review Focus

1. Esc while a `Modal` is open in fullscreen must close only the top modal and never leave fullscreen — test in Task 4.
2. Undo after the user re-added the same series (auto `recordWatched` created a new entry) must refuse with `conflict`, not create a duplicate — test in Task 1.
3. Back/forward shortcuts and mouse buttons must do nothing while the player overlay or a modal is open (otherwise the page behind the player changes) — test in Task 6.
4. A toast with “Undo” must not disappear under the mouse (timer paused on hover/focus) — test in Task 5.
5. Returning to a page must not re-request info already cached, yet an airing series' entry must expire at `airingAt + 1 h` — tests in Task 3.
