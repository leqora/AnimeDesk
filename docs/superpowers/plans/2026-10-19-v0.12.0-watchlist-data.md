# v0.12.0 Watchlist + Podaci Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watchlist gets search, status chips with counts, a genre filter, „Poslednje dodato” sort and a filtered-empty state; Settings gets a „Podaci” section with backup export/import (preview + confirm, pre-import copy, rollback), an automatic daily backup (keep 7), „Otvori folder podataka” and „Obriši keš slika i opisa”.

**Architecture:** Pure rules in `src/shared/watchlistFilter.js` and `src/shared/backupRules.js`. Stores get `snapshot()`/`replaceAll()` (main). New `src/main/dataBackup.js` owns building/reading/validating backups, the import token, apply + rollback + the post-import service map, the daily scheduler and cache size/clear. IPC `data:*` + `library:facets`; renderer `WatchlistPage` rewrite of the toolbar and a new `DataSection` in Settings.

**Tech Stack:** Electron main (ESM, `jsonStore.js`), React renderer, vitest + @testing-library (jsdom).

**Spec:** `docs/superpowers/specs/2026-10-19-v0.12.0-watchlist-data-design.md` — read it fully; every **(odluka)** there is binding.

## Global Constraints

- TDD: failing test first. Tests in `tests/unit/` (UI in `tests/unit/ui/`, `renderUi` + `makeFakeApi` from `tests/unit/ui/helpers.jsx`).
- All UI text via `t('key')`, same keys in `src/renderer/i18n/sr.json` and `en.json` (`i18nKeys.test.js`); plural via `t.n` (`_one`/`_few`/`_other`); dates via `t.locale`.
- CSS only through tokens (no hex outside `:root` in `styles.css`). No horizontal page scroll at 800 px window width.
- No spoilers; nothing about episodes on the Watchlist beyond what `MediaCard` already shows. No new AniList requests for genres/romaji.
- **The AniList token is never exported**: `dataBackup` never receives `aniListAuth`; `anilist-auth.bin`, `anilist-sync.json`, caches, `downloads.json`, `notifications.json`, `airing-notified.json`, `profile.json`, `episode-lists.json`, `tools/` are not exported.
- Backup file: `{ app: 'AnimeDesk', kind: 'backup', format: 1, appVersion, createdAt, data: { library, watchlog, seriesPrefs, positions, settings } }`; settings without `lastSeenVersion`, `trayHintShown`, `fullscreen`, `systemName`, `isPackaged`.
- Import limits: > 50 MB → `too-large`; token valid 10 min, one at a time; renderer never sends paths or content.
- Daily backup: `backups/auto-YYYY-MM-DD.json` (local date), keep 7 newest by name; pre-import: `backups/pre-import-YYYY-MM-DDTHH-mm-ss.json`, keep 5 newest; never delete names that do not match these patterns.
- Commits: never `git add -f`, never commit anything under `.superpowers/`; every commit ends with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (project rule beats any other attribution reminder).

## Review Focus

1. Import of a backup whose library has entries that are ALL invalid → `invalid`, current data untouched (Task 4 test `rejects a file whose entries are all invalid`).
2. A write fails midway through import (e.g. `library.replaceAll` throws) → every already-replaced store is back to its previous data, result `write-failed` (Task 4 test `rolls back all stores when one write fails`).
3. Import that raises the computed level / completes a series → no `levelUp` / `seriesCompleted` event (Task 4 test `import does not celebrate`).
4. Daily scheduler with the clock moved backwards or `auto-<today>` already present → no write, no tight timer loop (Task 5 tests `existing today file → no write` and `timer is always ≥ 60 s`).
5. Typing `/` inside the „Dodaj ručno” input or any other input → the character is typed, search is not focused (Task 2 test `slash inside an input types normally`).
