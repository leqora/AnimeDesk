# v0.22.0 „Dostignuća i statistika” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 21 achievements and new statistics on the Profile page, with unlock toasts held during playback and a single retroactive toast on the first 0.22.0 start.

**Architecture:** Pure rules in `src/shared/` (`localTime.js`, `achievements.js`, extended `stats.js`); the main process (`progress.js`) keeps unlocked ids in a new `achievements.json`, unlocks on `check()` and on `snapshot()` (= every `stats:get`), and announces through `celebrations` (held while an episode plays); the renderer shows the Profile sections and the toasts.

**Tech Stack:** Electron 45, React 19, vitest + Testing Library (`renderUi`, `makeFakeApi` from `tests/unit/ui/helpers.jsx`), lucide-react icons, CSS tokens in `styles.css`.

**Spec:** `docs/superpowers/specs/2026-11-04-v0.22.0-achievements-stats-design.md` (read it; it is the source of truth for copy and behavior).

## Global Constraints

- No spoilers: nothing about episode content anywhere (names, descriptions, toasts, stats). Only counts, times, and titles of series already in the library.
- No network for achievements or stats; only library, watch log and the AniList cache already read by `computeSnapshot` (`anilist.getCached`).
- Habit measures (streak, marathon, night owl, early bird, „Kada gledaš”, „Najduži niz”) count only watch-log items with `source === 'auto'`.
- Local day/hour always via `tzOffsetAt(iso)` (Date#getTimezoneOffset semantics: local = UTC − offset), like `computeStats`.
- Achievements give no XP; `xpFor`/levels unchanged. Once unlocked stays unlocked (except `rebase` after import).
- Storage: `%APPDATA%\AnimeDesk\achievements.json` = `{ version: 1, unlocked: { [id]: ISO } }`, never in `profile.json`; not in the backup export.
- All UI text via `t()` / `t.n()` with identical keys in `sr.json` and `en.json` (`i18nKeys.test.js`). No hex colors outside `:root`. No animations when `motionOff`.
- No new dependencies. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `git add` with explicit paths; never commit `.superpowers/`.

## Review Focus

1. Manual bulk marking (50 episodes at once, `source: 'manual'`) must not unlock `marathon`, `night-owl`, `early-bird`, streaks, nor feed „Kada gledaš” → test in Task 1 and Task 2.
2. DST change week and midnight/04:59/05:00 boundaries in a non-UTC zone → tests in Task 1 (`localHour`) and Task 2 (`weeklyHours` across 2026-10-25).
3. First 0.22.0 start with What's New dialog: the retro toast must not appear under/before the dialog, even when `takeRetro` resolves first → test in Task 5.
4. `achievements.json` corrupt or containing unknown ids / a series removed after unlocking → stays unlocked, no toast for re-derived set → tests in Task 3.
5. Achievement met only because the AniList cache arrived later (no library change) → unlocks on next `snapshot()` → test in Task 3.
