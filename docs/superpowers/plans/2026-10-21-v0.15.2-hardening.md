2. A zip entry name that is harmless on Linux but collides or escapes on Windows (`A.txt` vs `a.txt`, trailing dot/space, `:`) must fail the whole extraction — covered in Task 2.
3. One filler source being slow/down must never block or delay marks from the other, and must never erase marks already shown — covered in Task 4.
