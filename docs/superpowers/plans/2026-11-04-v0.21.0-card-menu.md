# v0.21.0 „Kontekst meni kartice” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desni klik / taster Menu / Shift+F10 na kartici serije otvara meni sa radnjama (Nastavi, Detalji, status, omiljeni, ukloni; traži/otvori, dodaj, ne preporučuj), plus klizač brzine u meniju plejera.

**Architecture:** Jedna zajednička `ContextMenu` komponenta (portal, pozicija iz čiste funkcije `placeMenu`, tastatura iz hook-a `useMenuKeys` izvučenog iz `MenuButton`) i hook `useCardMenu` koji se kači na koren kartice. Dve grupe stavki: `LibraryCardMenu` (kartice iz Watchlist-e) i `DiscoveryCardMenu` (preporuke/nastavci). Stranice se ne menjaju — biblioteka se osvežava kroz postojeći `api.onLibraryChanged`.

**Tech Stack:** Electron 45, React 19, vitest + @testing-library/react (jsdom), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-03-v0.21.0-card-menu-design.md` (pročitaj ceo, uključujući „Odluke posle builder check-a”).

## Global Constraints

- Nikakav podatak o epizodama u meniju osim broja („Nastavi EP N” = postojeći ključ `home.continueEp`).
- Svi tekstovi preko `t()`; isti ključevi u `src/renderer/i18n/sr.json` i `en.json` (`i18nKeys.test.js`).
- `styles.css`: samo postojeći CSS tokeni, bez hex boja van `:root`.
- React 19: logički DOM atributi kao `Boolean` (`inert={Boolean(x)}`), nikad `""`.
- Bez novog vidljivog „⋯” dugmeta; bez izvornog Electron menija.
- TDD: test koji pada → kod. UI testovi u `tests/unit/ui/` sa `renderUi` + `makeFakeApi` iz `tests/unit/ui/helpers.jsx`.
- Commit: identitet repoa, poruka na engleskom, završava sa `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `git add` uvek sa eksplicitnim putanjama; nikad `.superpowers/`.

Onemogućene (`aria-disabled="true"`) stavke ostaju fokusabilne (ARIA APG); ovo je izmena speca (spec je rekao „preskače”) — zapiši u spec jednom rečenicom.

Klik na stavku koja nije `aria-disabled` → posle njenog `onSelect` → `onClose('select')` ili `onClose('navigate')` ako stavka ima `navigates`.
  - `MenuItem({ icon?, onSelect, disabled = false, navigates = false, checked?: boolean, children })` — `button[type=button]`; sa `checked !== undefined` → `role="menuitemradio"` + `aria-checked`, inače `role="menuitem"`; `disabled` → `aria-disabled="true"` i klik ne radi ništa (meni ostaje otvoren); `tabIndex={-1}`.

  - `useCardMenu({ label: string }) → { rootProps: { ref, onContextMenu, onKeyDown }, open: boolean, menuProps: { label, position, onClose } }` — kači se na koren kartice:
    - `onContextMenu(e)`: ako je meta u `input, textarea, select, [contenteditable="true"]` → ništa. Ako je tastaturom otvoren meni u poslednjih 500 ms → samo `preventDefault`. Inače `preventDefault`, zapamti `document.activeElement` kao `returnTo`, otvori na `{ kind: 'pointer', anchor: { x: e.clientX, y: e.clientY, altY: e.clientY } }`.
    - `onKeyDown(e)`: `e.key === 'ContextMenu'` ili (`e.key === 'F10' && e.shiftKey`) → `preventDefault`, `returnTo` = `e.target`, otvori na `{ kind: 'anchor', anchor: { x: rect.left, y: rect.bottom + 4, altY: rect.top - 4 } }` gde je `rect` = koren kartice.
    - samo jedan meni: modul čuva `closeCurrent`; otvaranje novog zatvara prethodni.
    - `onClose(reason)`: zatvara; za `escape|outside|select|tab` vraća fokus na `returnTo` ako je `isConnected` i nije `disabled`, inače na glavno dugme kartice (`[data-card-main]` u korenu) ako nije `disabled`, inače `focusPage()`. Za `navigate|scroll|resize|blur|focusout` ne dira fokus.
    - **kartica nestaje dok je fokus u njoj ili u njenom meniju** (`useLayoutEffect` cleanup): ako je `document.activeElement` u korenu ili u meniju → posle mikrozadatka, ako je `activeElement` `body` ili `null`, `focusPage()`.
    - ne otvara se kad postoji `[aria-modal="true"]` ili kad je koren unutar `[inert]`.
  - `focusPage()` (izvezen iz `useCardMenu.js`) — ako fokus nije u `.toast-stack`, `document.querySelector('main.content')?.focus()`.
  - i18n (sr / en): `cardMenu.status` „Status” / „Status”; `cardMenu.remove` „Ukloni iz Watchlist-e” / „Remove from Watchlist”; `cardMenu.add` „Dodaj u Watchlist” / „Add to Watchlist”; `cardMenu.added` „Dodato u Watchlist: {title}” / „Added to Watchlist: {title}”; `cardMenu.already` „Već je u Watchlist-i: {title}” / „Already in your Watchlist: {title}”; `cardMenu.search` „Traži” / „Search”; `cardMenu.open` „Otvori” / „Open”; `cardMenu.notRecommend` „Ne preporučuj” / „Don't recommend”; `cardMenu.hide` „Sakrij” / „Hide”.
