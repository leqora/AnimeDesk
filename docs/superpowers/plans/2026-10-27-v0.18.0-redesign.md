# v0.18.0 Redizajn (traka gore + baneri + nova Početna) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zameniti bočni meni gornjom trakom, uvesti AniList banere (fajlovi + protokol `animedesk-img:`) i napraviti novu Početnu u Crunchyroll stilu (baner koji se smenjuje, 16:9 „Nastavi gledanje”, baner popularnih kad nema serija u toku).

**Architecture:** Main proces dobija `bannerUrl`/`format` iz postojećih AniList upita, čuva banere kao fajlove u `cache/banners` i služi ih kroz sopstveni protokol; renderer nikad ne vidi AniList URL banera, samo `animedesk-img://banner/<sha1>` preko novog IPC-a `anilist:banner` koji primenjuje pravilo postera. Renderer: `TopBar` (preko `main.content`, providna nad banerom), `HomeHero` (smenjivanje), `PopularHero`, `ContinueCard` (16:9).

**Tech Stack:** Electron 45 (`protocol.handle`, `net.fetch`), React 19, Vitest + Testing Library (`renderUi`, `makeFakeApi` iz `tests/unit/ui/helpers.jsx`), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-10-27-v0.18.0-redesign-design.md` (ovaj plan pokriva tačke 1–15 i 21–28 samo za Početnu, Otkrij i zajedničke kartice/šine/dugmad; tačke 16–20 i E za ostale stranice su v0.19.0). Vizuelna referenca: `.superpowers/brainstorm/689-1793057092/content/home-crunchy-ours-v4.html` (samo čitati, nikad ne commit-ovati `.superpowers/`).

**Interfaces:**
- Produces (Zadatak 3):
  - `createBanners({ dir, fetchImpl = fetch, timeoutMs = 10_000, maxBytes = 3 * 1024 * 1024 }) -> { ensure, resolve, forget }`
  - `ensure(url: string) -> Promise<string|null>` — vraća `animedesk-img://banner/<sha1(url) hex>` kad fajl postoji ili je upravo upisan, inače `null`.
  - `resolve(requestUrl: string) -> { path: string, type: string } | null` — za handler protokola.
  - `forget()` — briše pamćenje neuspeha i tekuća preuzimanja (posle „Obriši keš”).
  - Konstanta `BANNER_SCHEME = 'animedesk-img'`.

- [ ] **Step 1: Write the failing tests** (`tests/unit/banners.test.js`, privremeni folder po testu)
  - `ensure downloads once and serves the file`: `https://s4.anilist.co/file/anilistcdn/media/anime/banner/1-x.jpg`, odgovor `image/jpeg` → vraća `animedesk-img://banner/<40 hex>`, fajl `<hash>.jpg` postoji; drugi poziv → isti URL bez novog `fetchImpl`.
  - `concurrent ensure shares one download`: dva istovremena poziva → `fetchImpl` pozvan jednom.
  - `rejects other hosts and schemes`: `http://s4.anilist.co/...`, `https://evil.example/...`, `https://s4.anilist.co.evil/...`, URL sa korisnikom/portom → `null`, bez `fetchImpl`.
  - `rejects wrong type, too large and slow`: `text/html` → `null`; `content-length` > 3 MB ili telo > 3 MB → `null` i nema fajla; preko roka 10 s (lažni tajmer/`AbortSignal`) → `null`; neuspeh se ne ponavlja do `forget()`.
  - `resolve maps only a known hash`: `animedesk-img://banner/<hash postojećeg>` → `{ path, type: 'image/jpeg' }`; nepostojeći hash, `../`, velika slova, drugi host (`animedesk-img://x/<hash>`) → `null`.
  - `csp.test.js`: očekivani CSP sa `img-src 'self' data: animedesk-img:`.

- [ ] **Step 2: Run** `npx vitest run tests/unit/banners.test.js tests/unit/csp.test.js` → FAIL.

- [ ] **Step 3: Implement**
  - Dozvoljeno: `https:`, host tačno `s4.anilist.co`, bez korisnika/porta; tipovi `image/jpeg|png|webp` → ekstenzije `jpg|png|webp`; upis `wx` u privremeni fajl pa `rename`; `resolve` prihvata samo `^[0-9a-f]{40}$` i traži `<hash>.(jpg|png|webp)` u `dir`.
  - `index.js`: na vrhu modula `protocol.registerSchemesAsPrivileged([{ scheme: BANNER_SCHEME, privileges: { standard: true, secure: true } }])`; posle `app.whenReady()` `protocol.handle(BANNER_SCHEME, (req) => { const f = banners.resolve(req.url); return f ? net.fetch(pathToFileURL(f.path).toString()) : new Response(null, { status: 404 }) })`; `cacheDirs` dobija `paths.banners` (time veličina i brisanje keša), `onCacheCleared` zove `banners.forget()`.
