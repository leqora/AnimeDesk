# v0.23.0 „Pregled kadra na traci” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A frame thumbnail above the internal player's seek bar while the mouse hovers it, spoiler-safe and without hurting playback.

**Architecture:** Pure rules in `src/shared/framePreview.js`; the main process decides the mode per episode (`seriesEpisodes.framePreview` → `'off'|'full'|'reached'`); a renderer hook drives a second hidden `<video>` (own hls.js instance for streams, plain `src` for files), captures frames to small JPEG data URLs and caches them; `PlayerTimeline` shows the frame above the existing time tooltip.

**Tech Stack:** Electron 45, React 19, hls.js 1.7.4, vitest + Testing Library (jsdom), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-04-v0.23.0-frame-preview-design.md` (Serbian; read it in full).

## Global Constraints

- No new dependencies; no changes to `streamServer.js`, ani-cli flow, `mpvConfig.js`, or the main stream's quality.
- Main process decides the mode; renderer only applies it. Fail closed: unknown/error/not-yet-answered → `'reached'`.
- `'full'` only if the episode is in `entry.watchedEpisodes` (string/number compare as numbers), or revealed (`reveal.all` / `reveal.episodes`), or `settings.hideSpoilers === false`. Gaps below the max watched episode are `'reached'`. `metaOff` does not matter. `settings.framePreview === false` → `'off'`.
- Frontier: starts at `open.resumeAt ?? 0`; grows only when, while not seeking, `0 < time - lastTime ≤ 3`; any `timeupdate` between `seeking` and `seeked` is ignored, and `lastTime` is set to the time after `seeked`.
- Network guard for HLS (user's choice „sa zaštitom”): new fetch only if main video has ≥ 15 s buffered ahead **or** is paused; main not buffering, not failed/reconnecting, `readyState ≥ 3`; nothing in flight; < 12 fetches started in the last 60 s (cache hits don't count). Files: only "one at a time".
- Nothing is created or fetched before the first hover of the episode; mouse leave → `stopLoad()`; destroy on unmount, mini, or 60 s without hover.
- Preview errors are silent and turn preview off for that episode; they never reach the main player's `onFatal`.
- No preview in mini player, external mpv, keyboard or touch.
- Frame box is `aria-hidden`; tooltip text/role unchanged. Without the `preview` prop `PlayerTimeline` renders exactly as today.
- All UI copy via `t()`, same keys in `sr.json` and `en.json`. CSS colors only as tokens (no hex outside `:root`, `styles.test.js`).
- Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `git add` with explicit paths; never commit `.superpowers/`.

## Review Focus

1. Episode change (auto-next, new episode, recovery) while a preview seek is in flight → no frame of the old episode ever shows (Task 3 test: unmount destroys hls, removes element, ignores late `seeked`).
2. Fast mouse sweep across the whole bar → only the final resting position is fetched, never one fetch per pixel (Task 3 test: debounce + single in-flight).
3. Frontier grows while the mouse rests above it → next request at the same spot is re-evaluated, not stuck on "no frame" (Task 3 test: request re-checks `frontierRef.current`).
4. Setting turned off mid-episode → no box, no fetch immediately, without waiting for a new episode (Task 4 test: `settings.framePreview === false` forces `'off'`).
5. Hover before metadata / during resume prompt / while the main video is failed → time-only tooltip as today, no fetch (Task 4 test: `failed` blocks fetch; existing `known` guard keeps tooltip off without duration).

### Task 1: Pure rules `src/shared/framePreview.js`

**Files:**
- Create: `src/shared/framePreview.js`
- Test: `tests/unit/framePreview.test.js`

**Interfaces:**
- Produces:
  - constants `PREVIEW_MIN_AHEAD_S = 15`, `PREVIEW_WINDOW_MS = 60000`, `PREVIEW_MAX_FETCHES = 12`, `PREVIEW_BUCKET_S = 5`, `PREVIEW_CACHE_MAX = 120`, `PREVIEW_DEBOUNCE_MS = 120`, `PREVIEW_IDLE_MS = 60000`, `PREVIEW_SEEK_TIMEOUT_MS = 8000`, `FRONTIER_MAX_STEP_S = 3`
  - `advanceFrontier(frontier: number, lastTime: number, time: number, seeking: boolean) => number`
  - `previewAllowed(mode: 'off'|'full'|'reached'|string, at: number, frontier: number) => boolean` (`off` → false, `full` → true, anything else → `at <= frontier`)
  - `bucketOf(t: number) => number` (`Math.floor(t / PREVIEW_BUCKET_S)`)
  - `bufferedAhead(ranges: {start:number,end:number}[], time: number) => number` (end of the range containing `time` minus `time`; 0 if none; a range starting ≤ 0.5 s after `time` counts as containing it)
  - `canFetch({ kind: 'hls'|'file', inFlight: boolean, mainPaused: boolean, ahead: number, buffering: boolean, failed: boolean, readyState: number, recent: number[], now: number }) => boolean`
  - `pruneRecent(recent: number[], now: number) => number[]` (keeps stamps `now - t < PREVIEW_WINDOW_MS`)
  - `createFrameCache(max = PREVIEW_CACHE_MAX) => { get(bucket): string|undefined, set(bucket, src): void, nearest(bucket): { bucket, src }|null, clear(): void, readonly size: number }` — LRU on `get`/`set`; `nearest` checks `bucket`, then `bucket-1`, then `bucket+1`, and does not touch LRU order.

  - `fatal preview error is silent`: `emitError(NETWORK_ERROR, true)` → `destroy` called, later `hover` does nothing (`frame.allowed === false`), and no callback other than internal state is invoked (hook has no `onFatal`).
