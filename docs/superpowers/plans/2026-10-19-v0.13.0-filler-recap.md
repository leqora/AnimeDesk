# v0.13.0 Filler/recap oznake + stabilna traka Watchlist-e — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Episode pickers show spoiler-safe filler/recap marks from Jikan (MyAnimeList) with a per-series "hide" toggle, and the Watchlist toolbar no longer jumps when the scrollbar appears/disappears.

**Architecture:** New main module `src/main/fillerInfo.js` (Jikan client: own disk cache, one shared rate-limited queue, background-only fetching) + pure rules `src/shared/episodeMarks.js`. `src/main/seriesEpisodes.js` stays the only gate to the renderer: it reads the cache synchronously, adds `kind` per episode and `marks`/`markCounts` per series, and triggers a background fetch whose completion is announced with a payload-less `event:episodes-changed`. Renderer (`EpisodePicker`, `EpisodeRow`, pages, Settings) only displays what main sent.

**Tech Stack:** Electron (main, Node fetch), React 18, vitest + Testing Library, plain CSS tokens.

**Spec:** `docs/superpowers/specs/2026-10-19-v0.13.0-filler-recap-design.md` (Serbian; read it fully — every **(odluka)** there is binding).

## Global Constraints

- ani-cli untouched; no new npm dependencies.
- Every new episode-related field reaching the renderer goes through `src/main/seriesEpisodes.js`; `fillerInfo` has no IPC channel.
- From Jikan only episode numbers + `filler`/`recap` booleans are kept (whitelist); titles, dates, scores never reach disk or renderer.
- Never fetch Jikan at app start or on a timer — only from `seriesEpisodes.forSeries` (and `spoilers`, which returns `forSeries`). Never from `thumb`.
- Jikan unavailable ⇒ list renders immediately, no UI error, no request loop.
- All UI text via `t()`; same keys in `src/renderer/i18n/sr.json` and `en.json`; CSS colors only as tokens (no hex outside `:root`).
- No spoilers in tests/notes: use invented episode numbers, never claim a real series' episode is filler.
- TDD; tests in `tests/unit/` (UI in `tests/unit/ui/`, `renderUi` + `makeFakeApi` from `helpers.jsx`). Code/comments/commits in English.
- Commits end with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (this project rule beats any default model trailer). Never `git add -f`, never commit `.superpowers/`.

## Review Focus

1. Jikan down or hanging: opening the same series 10× in a minute makes at most one fetch attempt per `malId` per hour; `forSeries` never awaits the network for marks — Task 1 test "pause after failure", Task 2 test "forSeries does not wait for ensure".
2. Opening several series quickly: all Jikan requests (across `malId`s) start ≥ 1100 ms apart and never overlap — Task 1 test "shared queue spacing".
3. Airing series where ani-cli already lists 1–5 episodes more than MAL: marks stay `ok`; 6+ more ⇒ `unreliable`; finished series with even 1 more ⇒ `unreliable` — Task 2 (`episodeMarks`) tests.
4. Labels `"0"`, `"12.5"`, `"SP"` are never marked even if Jikan has that number — Task 2 test.
5. Imported backup with `hideFiller: "yes"` / `episodeMarks: 1` is sanitized away (default kept) — Task 2 tests in `seriesPrefs.test.js` / `settings.test.js`.

**Interfaces:**
- Produces (exports of `src/main/fillerInfo.js`):
  - constants `JIKAN_URL = 'https://api.jikan.moe/v4/anime'`, `TTL_MS = 30 days`, `AIRING_TTL_MS = 7 days`, `MISSING_TTL_MS = 7 days`, `RETRY_AFTER_MS = 1 h`, `GAP_MS = 1100`, `RATE_PAUSE_MS = 60000`, `MAX_RATE_RETRIES = 2`, `MAX_PAGES = 30`, `TIMEOUT_MS = 15000`
  - `slimJikanPage(raw) -> { episodes: Array<{ n: number, kind: 'filler' | 'recap' | null }>, hasNext: boolean }` — keeps only items with integer `mal_id >= 1`; `recap === true` ⇒ `'recap'` (wins over filler), else `filler === true` ⇒ `'filler'`, else `null`; `hasNext = raw?.pagination?.has_next_page === true`.
  - `createFillerInfo({ cacheDir, fetchImpl = fetch, now = Date.now, sleep = (ms) => new Promise((r) => setTimeout(r, ms)) })` returning:
    - `cached(malId, { airing = false } = {}) -> null | { filler: number[], recap: number[], count: number, fetchedAt: number, missing?: true, expired: boolean }` — synchronous disk read (no network); `expired` from `MISSING_TTL_MS` / `AIRING_TTL_MS` / `TTL_MS`.
    - `ensure(malId, { airing = false } = {}) -> Promise<boolean>` — never rejects; resolves `true` only when a non-missing record was written; `false` when cache still fresh, `malId` invalid (not integer > 0), in the 1 h pause, or on any failure.
    - `forget()` — drops in-memory state (parsed-file memo, `failedAt`) after the cache folder was deleted.
  - Disk file `<cacheDir>/<malId>.json`: `{ filler: number[], recap: number[], count, fetchedAt }` (sorted ascending) or `{ missing: true, fetchedAt }`.

  - `stops after MAX_PAGES` — `has_next_page` always true ⇒ exactly 30 requests, record written.
  - `request timeout aborts after TIMEOUT_MS` — fetch that never resolves until its `signal` aborts ⇒ failure path (use real timers for this one or `vi.useFakeTimers`).
