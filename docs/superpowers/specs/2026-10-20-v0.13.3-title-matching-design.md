Datum: 2026-10-20 (posle builder check-a na Opus-u — 14 nalaza ugrađeno; jedno pitanje odlučio korisnik, ostalo kontrolor po pravilima projekta, označeno). Grana: `feat/v0.13.3-title-matching` (od `cc79427`). Korisnik je u chatu dobio predlog (4 tačke: čišćenje upita, izbor po sličnosti umesto prvog rezultata, verzija i na uspešnim pogocima, id u detalju samo za siguran pogodak) i **odobrio ga** („Odobravam kreni”). Ono što je bilo u predlogu piše se bez oznake; detalji koje je kontrolor dodao označeni su **(odluka)**.

## Zašto

Izmereno 2026-10-20 na instaliranoj 0.13.2 (izolovan profil, pravi ani-cli + AniList), 11 pretraga / 282 kartice: **17 praznih** (svi pravo „nije nađeno”, bez 429) i **~6 jasno pogrešnih** postera + ~7 susedna sezona. Uzroci (proveravano uživo):

- AniList pretraga zahteva **sve reči** upita: „Bleach: Thousand-Year Blood War **Arc**”, „JoJo's Bizarre Adventure **(Uncensored)**”, „Saint Seiya: The Lost Canvas **(season 1+season 2)**” ne vraćaju ništa; bez viška reči se nađu (#116674, #6171).
- Kad ceo naslov ne prođe, `searchCandidates` pokuša podnaslov / deo pre `:` / očišćen naslov, a `bestMatch` uzme **`results[0]`** kad nema tačnog poklapanja → „Lupin III: Goodbye Lady Liberty” → „The Woman Called Fujiko Mine” (preko „Lupin III”), „Macross Δ Movie: Gekijou no Walküre” → „Pajama no Megami-tachi”, Lost Canvas → Saint Seiya (1986).
- Posledica je šira od postera: `AnimeDetail.jsx:71` pri otvaranju upiše `aniListId` iz pogotka po naslovu → pogrešni nastavci, raspored, sličice/naslovi epizoda (ani.zip), filler i AniSkip; `seriesEpisodes.js` (put samo po naslovu), `skipLookup.js` i `sequels.js` (`getCachedId`) koriste podatke pogotka po naslovu i bez toga.

**Korpus za proveru pravila** (snimljeno 2026-10-20): ani-cli naslovi iz 20 pretraga (gundam, macross, saint seiya, naruto, dragon ball, fate, monogatari, jojo, lupin, gintama, bleach, one piece, attack on titan, sword art online, pokemon, detective conan, love live, precure, evangelion, ghost in the shell) = **483 različita naslova**, i pravi AniList odgovori (top 10 + `synonyms`/`format`) za 1396 upita koje staro ili novo pravilo šalje. Van mreže, staro vs. novo pravilo (dodatak A):

| | staro | novo |
|---|---|---|
| tačno poklapanje naslova | — | 315 |
| blizak pogodak (sličnost) | — | 116 |

Prazan/blizak pogodak korisnik može da ispravi ručnim izborom (`AniListMatch` u detalju — od ove verzije i bez AniList prijave, tačka 17).

**Seanime** (`_ref/seanime`, pogledano u kodu): za online izvore bira rezultat sa najmanjom Levenshtein razdaljinom prema svim AniList naslovima (`onlinestream.GetBestSearchResult`), bez praga; za lokalne fajlove MAL `search/prefix.json` + Levenshtein (`mal.AdvancedSearchWithMAL`; MAL odgovara 200). Od Seanime-a uzimamo poređenje sa **svim** naslovima uključujući sinonime; za razliku od njih imamo prag (pogrešan poster je gori od praznog) jer naši pogoci određuju i id za epizode/AniSkip. MAL ne koristimo (nov spoljni servis bez potrebe).

Spoljni servis: samo AniList (radi, 2026-10-20). Nema novog servisa.

## Ciljevi

### A. Čisto pravilo uparivanja: `src/shared/titleMatch.js` (novi modul, bez I/O)

1. Izvozi `MATCH_VERSION = 3`, `cleanTitle(title)`, `searchQueries(title)`, `pickMatch(title, results)`, `isExactName(title, name)` **(odluka: za prevođenje starog keša, tačka 10)**. **Kod iz dodatka A je normativan** (port u modul uz TDD); konstante (`0.6`, `0.25`, opšte reči, rimski brojevi) se ne menjaju bez ponovnog merenja korpusa.
2. `cleanTitle`: ukloni `[…]` i `(…)` delove, `;` na kraju, reč „Arc” na kraju; skupi razmake (= `strip` u dodatku A).
3. `searchQueries(title)` = bez duplikata, redom: ceo naslov (trim), `cleanTitle(title)`, pa današnji rezervni nazivi (`searchCandidates`, ista logika, seli se iz `anilist.js`) **očišćenog** naslova. Prazni se izbacuju.
4. `pickMatch(title, results)` → `{ media, match: 'exact' | 'close' } | null` (dodatak A):
   - **tačno** (`isExactName`): `norm` jednak naslovu ili očišćenom naslovu, ili isti niz reči posle `toks`. Prvo se traži među glavnim naslovima (romaji/english/native) svih rezultata, tek onda među `synonyms` („Lupin III” → #1412, ne sinonim „Lupin III” serije #13203);
   - **blizak**: najbolja `score(očišćen naslov, media)` ≥ 0,6 (pri jednakoj oceni prvi rezultat), i očišćen naslov ima ≥ 2 različite prepoznatljive reči (naslov od jedne reči — „Pokémon” — prihvata samo tačno);
   - inače `null`.
5. Normalizacije (normativno, dodatak A): `loose` = mala slova, NFKD bez dijakritika, sve što nije slovo/cifra → razmak; `toks` razdvaja **samo slovo→cifra** („OVA2” → „ova 2”; „2nd” ostaje jedna reč pa postaje „2”); redni brojevi i vodeće nule po ASCII `\b` (bez `u` zastavice), rimski II/III/IV/VI i second/third → broj; broj 1 se ne računa u proveri brojeva. `dice(a, b)` = Sørensen–Dice nad **parovima znakova stringova `loose` sa razmacima**, svaki par onoliko puta koliko se javlja (multiskup), `2·presek / (|A|+|B|)`, a za `|A|+|B| = 0` → 0; `wdice` = isto nad **skupom** reči `toks`. Bez mreže, bez sata.

### B. `src/main/anilist.js` koristi pravilo

6. `FIELDS` (`anilistQueries.js`) dobija `synonyms`. `toInfo` ga **ne** čuva (keš ne raste).
7. `findByTitle(title)`: za svaki upit iz `searchQueries(title)` (kroz postojeći `batcher.search`) → `pickMatch(title, results)`; prvi pogodak završava. Pravila grešaka ostaju (`complete`, 429 → staje bez daljih upita). `bestMatch` i `searchCandidates` se brišu iz `anilist.js` (testovi se prenose na `titleMatch`).
8. **(odluka — jedna konstanta)** `SEARCH_VERSION = MATCH_VERSION` (3); komentar uz nju: menja se kad god se menja `titleMatch`. Zapis pogotka po naslovu dobija `match: 'exact' | 'close'` i `matchVersion: SEARCH_VERSION`; zapis po id-u (`aniListId`) dobija `match: 'id'` (bez `matchVersion`). „Nije nađeno” nosi `searchVersion` kao danas (stari se odmah ponovo proveravaju).
9. `getForTitle` bez id-a, zapis po naslovu (ne „nije nađeno”):
   - **trenutna verzija** (`matchVersion === SEARCH_VERSION`): ponašanje kao danas (`isFresh`; zastareo → nova pretraga; neuspeh ili potpuna pretraga bez pogotka → stari zapis kao rezerva, `failed()` + pauza 1 h; test „does not write a notFound marker over a stale entry” ostaje).
   - **stara verzija ili bez `matchVersion`**: prvo prevođenje bez mreže (tačka 10); ako se ne prevede, zapis je zastareo **bez obzira na `isFresh`** → nova pretraga (postojeća zaštita `refreshAttemptAt` i `inflight` važe). Ako pretraga završi **cela** (`complete`) bez pogotka: upiše se „nije nađeno” (sa `searchVersion`), obriše se `refreshAttemptAt` za taj fajl i vraća `null` (NE `failed()` — stari, verovatno pogrešan pogodak se ne vraća). Ako ne završi cela (mreža/429): stari zapis kao rezerva, bez upisa (`failed()` kao danas). Nov pogodak sa drugim `coverUrl` preuzima nov poster (postojeće pravilo).
10. **(odluka — nalaz builder check-a: bez prevođenja bi posle ažuriranja svaki keširan naslov išao na mrežu, ~80–90 zahteva za merni profil, i verovatno obaveštenje o limitu)** Prevođenje starog zapisa bez mreže: ako je `isExactName(title, x)` za `x` ∈ sačuvani `title`/`romaji` zapisa, zapis se na disku dopuni sa `match: 'exact'`, `matchVersion: SEARCH_VERSION` (ostalo isto) i vraća se kao trenutna verzija (dalje tačka 9, prvi deo). Ostali stari zapisi idu u novu pretragu.
11. `getCached(title, { aniListId })` ostaje isti (sinhrono, vraća zapis kakav jeste, i stari bez `match`). Kad tačka 9 zameni stari zapis sa „nije nađeno”, `getCached` vraća `null` — žanrovi u Watchlist filteru i trajanje u statistici profila za tu seriju nestaju (sati padaju na podrazumevano trajanje epizode); XP ne zavisi od toga. Prihvaćeno (to su bili podaci pogrešne serije).
12. Ne menjaju se: `search()` (IPC `anilist:search`), `candidates()`, `refreshAiring`, `relations`, nalog/sinhronizacija, red zahteva i grupisanje (v0.13.2).

### C. Šta sme blizak pogodak (samo prikaz)

13. **Pravilo (odluka, sledi iz tačke 4 predloga i pravila „bez spojlera”):** `close` pogodak služi samo za prikaz **postera, naslova, romaji naslova, godine i žanrova**. Sve što iz pogotka vuče dalje podatke, pamti id ili prikazuje podatke o emitovanju/epizodama koristi pogodak po naslovu **samo kad `match !== 'close'`** (`exact`, `id` ili stari zapis bez `match` — stari id-zapisi ga nemaju jer `refreshAiring` samo dopunjuje polja):
    - `AnimeDetail.jsx` (unos **bez** `aniListId`): `patch.aniListId` i `patch.totalEpisodes` samo kad `info.match === 'exact'`; za unos sa `aniListId` pravilo za `totalEpisodes` ostaje kao danas. **(odluka)** Preskočen blizak pogodak NE troši `patchedFor` — ako kasnije stigne tačan pogodak za isti unos (npr. posle ručnog izbora), upis se desi.
    - `AnimeDetail.jsx` za `close`: bez opisa (`info.description`), bez broja epizoda/trajanja/AniList statusa u redu meta podataka i bez „EP N izlazi za…” / „N novih”.
    - `seriesEpisodes.js` (put samo po naslovu, bez `knownId`): za pogodak koji nije `exact` → `info = null` i `id = null` — bez ani.zip naslova/sličica i **bez filler oznaka** (`marksFor` čita `info.malId`); `fillerInfo.ensure` se ne zove.
    - `skipLookup.js`: bez `findAniListId(title)` i `info.match === 'close'` → prazni intervali (bez AniSkip-a — pogrešan interval preskače sadržaj).
    - `createTotalEpisodes` (`skipLookup.js`): broj epizoda iz keša po naslovu samo kad `match !== 'close'`.
    - `sequels.js` `getCachedId`: id iz keša po naslovu samo kad `match === 'exact'` (stari zapisi bez `match` se do prevođenja/ponovne provere ne računaju; prevođenje iz tačke 10 vraća tačne odmah pri prvom prikazu).
    - `src/shared/airing.js` `newEpisodeCount` → 0 i `upcoming` → `null` kad `info.match === 'close'` (pokriva Hero, MediaCard, detalj).
    - `useAniListInfo` `live`: bez tajmera osvežavanja kad `info.match === 'close'`.
    - renderer `infoCache.js`: rezultat po naslovu se upisuje/javlja i pod ključem `id:<info.id>` **samo kad `info.match !== 'close'`** (inače bi drugi unos koji zaista ima taj id dobio „close” podatke).
14. Već upisani `aniListId` u biblioteci se ne diraju. **(odluka — svesno ostavljeno: nema automatske „popravke” starih upisa; korisnikov pravi profil je prazan, a automatsko brisanje id-a bi moglo da obriše ispravan izbor.)**

## Dodatak A — referentno pravilo (normativno; proveravano na korpusu i nezavisno u builder check-u)

```js
const norm = (s) => String(s ?? '').toLowerCase().replace(/[^\p{L}\p{N}]+/gu, '') // isto kao anilist.js
const strip = (t) => t.replace(/\[[^\]]*\]/g, ' ').replace(/\([^)]*\)/g, ' ').replace(/;+\s*$/g, '').replace(/\s+arc\s*$/i, '').replace(/\s+/g, ' ').trim() // = cleanTitle
const loose = (s) => String(s ?? '').toLowerCase().normalize('NFKD').replace(/\p{M}+/gu, '').replace(/[^\p{L}\p{N}]+/gu, ' ').trim()
const ROMAN = { ii: '2', iii: '3', iv: '4', vi: '6', second: '2', third: '3' }
const toks = (s) => loose(s).replace(/(\p{L})(\d)/gu, '$1 $2').replace(/\b0*(\d+)(?:st|nd|rd|th)?\b/g, '$1').split(' ').filter(Boolean).map((w) => ROMAN[w] ?? w)
const nums = (s) => new Set(toks(s).filter((w) => /^\d+$/.test(w) && w !== '1'))
const GENERIC = new Set('movie movies film the a an of no to wa ga season part special specials ova ona oad tv recap cour arc episode episodes ep vs x and new version edition uncensored dub sub raw complete series s'.split(' '))
const distinctive = (s) => toks(s).filter((w) => !GENERIC.has(w) && !/^\d+$/.test(w))
const MOVIE = /\b(movie|film|gekijouban)\b/i
function bigrams(s) { const out = new Map(); for (let i = 0; i < s.length - 1; i++) { const b = s.slice(i, i + 2); out.set(b, (out.get(b) ?? 0) + 1) } return out }
function dice(a, b) {
  const A = bigrams(a), B = bigrams(b); let inter = 0, na = 0, nb = 0
  for (const v of A.values()) na += v; for (const v of B.values()) nb += v
  for (const [k, v] of A) inter += Math.min(v, B.get(k) ?? 0)
  return na + nb ? (2 * inter) / (na + nb) : 0
}
function wdice(a, b) { const A = new Set(toks(a)), B = new Set(toks(b)); let i = 0; for (const x of A) if (B.has(x)) i++; return A.size + B.size ? 2 * i / (A.size + B.size) : 0 }
const MAIN = (m) => [m.title.romaji, m.title.english, m.title.native].filter(Boolean)
const namesOf = (m) => [...MAIN(m), ...(m.synonyms ?? [])].filter(Boolean)
function score(title, m) { // title = očišćen naslov
  const tn = nums(title)
  const numOk = (n) => [...nums(n)].every((x) => tn.has(x))
  if (![m.title.romaji, m.title.english].filter(Boolean).some(numOk)) return -1
  const names = namesOf(m).filter(numOk)
  const tokSet = new Set(namesOf(m).flatMap(toks))
  const joined = namesOf(m).map(norm).join('|')
  const want = [...new Set(distinctive(title))]
  const missing = want.filter((w) => !tokSet.has(w) && !(w.length >= 3 && joined.includes(w)))
  if (missing.length && missing.length / want.length > 0.25) return -1
  const seps = [...title.matchAll(/:|\s-\s/g)]
  if (seps.length && missing.length) {
    const last = seps.at(-1)
    const sub = new Set(distinctive(title.slice(last.index + last[0].length)))
    if (missing.some((w) => sub.has(w))) return -1
  }
  let best = 0
  for (const n of names) best = Math.max(best, (dice(loose(title), loose(n)) + wdice(title, n)) / 2)
  if (MOVIE.test(title)) best += m.format === 'MOVIE' ? 0.1 : (m.format === 'TV' || m.format === 'TV_SHORT') ? -0.15 : 0
  return best
}
const exactTok = (a, b) => toks(a).join(' ') === toks(b).join(' ')
// isExactName(title, name)
const isExactName = (title, n) => { const s = strip(title); return norm(n) === norm(title) || norm(n) === norm(s) || exactTok(title, n) || exactTok(s, n) }
function pickMatch(title, results) {
  const s = strip(title)
  const isEx = (n) => isExactName(title, n)
  const ex = results.find((m) => MAIN(m).some(isEx)) ?? results.find((m) => namesOf(m).some(isEx))
  if (ex) return { media: ex, match: 'exact' }
  let best = null, bs = -1
  for (const m of results) { const sc = score(s, m); if (sc > bs) { bs = sc; best = m } } // jednaka ocena → ostaje prvi
  if (bs >= 0.6 && new Set(distinctive(s)).size >= 2) return { media: best, match: 'close' }
  return null
}
```
