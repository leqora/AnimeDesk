# AnimeDesk v0.7.0 — spoiler model + metapodaci epizoda (spec)

Datum: 2026-10-11
Status: čeka pregled
Izvor: `docs/seanime-analysis/04-plan.md` §3 P1 (spoiler model, keš stvarne ani-cli liste) i P2 (metapodaci epizoda — prebačeno u v0.7.0), `03-oblast-epizode.md` §1–3, §8–9.

## 1. Cilj

Lista epizoda dobija naslove, sličice, trajanje i opise (ani.zip), a **spoiler model** garantuje da se za epizode koje korisnik još nije trebalo da vidi ništa od toga ne prikaže — ni u DOM-u, ni u atributima, ni u memoriji renderera, ni u kešu slika. Detalj serije prikazuje stvarnu ani-cli listu epizoda umesto `1..max`.

### Odluke korisnika (brainstorming 2026-10-11)
1. Spoiler model ide **zajedno sa metapodacima epizoda** (inače nema šta da štiti ni da se ručno proveri). Metapodaci se iz P2 prebacuju u v0.7.0.
2. **Pravilo:** M = najveća odgledana epizoda. Epizode ≤ M su vidljive (i rupe ispod M), **sledeća (≤ M+1) prikazuje naslov i sličicu**, sve posle nje je skriveno.
3. **Opis epizode** samo za odgledane / otkrivene epizode (≤ M ili otkrivene), i to **iza klika**; sledeća epizoda nema opis.
4. **Prikaz:** prekidač **Brojevi / Lista**, pamti se globalno; pilule ostaju gust prikaz.
5. **Otkrivanje** po seriji i po epizodi, **pamti se trajno** (`series-prefs.json`), uz „Ponovo sakrij otkrivene”.
6. **Površine:** detalj serije + Pretraga (obe kroz `EpisodePicker`). Plejer i Početna se ne menjaju.
7. **Obim v0.7.0:** spoiler model + metapodaci + keš stvarne ani-cli liste. Ostatak P1 (redizajn kartice, progres po epizodi, „sledeća izlazi…”/„N novih”, istorija navigacije, `Modal.jsx`, toastovi, keš postera) ide u v0.7.1+.
8. **Pristup 1:** spoiler pravilo se primenjuje u **main procesu**; renderer dobija već očišćene podatke.
9. Globalni prekidač „Skrivaj spojlere” u Podešavanjima, **podrazumevano uključen**; kad je isključen, sve epizode su `full` (opis i dalje iza klika).
10. Režim „ne renderuj” (ne CSS blur).

### Kriterijumi uspeha
- Za seriju sa odgledanim 1–3 (zaštita uključena): u prikazu Lista epizode 1–3 imaju sličicu, naslov i „Opis”; epizoda 4 ima sličicu i naslov bez „Opis”; epizode 5+ imaju poster serije, „Epizoda N” i „Prikaži”.
- Za skrivenu epizodu odgovor IPC-a (serijalizovan) ne sadrži njen naslov, URL slike ni opis; main ne preuzima njenu sličicu.
- „Prikaži” na epizodi i „Prikaži sve epizode ove serije” ostaju posle ponovnog pokretanja; „Ponovo sakrij otkrivene” ih briše.
- Detalj serije koju je korisnik gledao kroz aplikaciju (posle 0.7.0) prikazuje tačno epizode iz ani-cli menija (uključujući „0”/decimale).
- Kad ani.zip nije dostupan (nema mreže, nema serije), sve radi kao u 0.6.5 (brojevi), bez poruke o grešci.
- Ako ani-cli ima više celih epizoda od ani.zip `episodeCount`, metapodaci se ne prikazuju (napomena „brojevi se ne poklapaju”).

### Van opsega
Naslovi epizoda u plejeru (`NextEpisodeCard`, naslov plejera) i na Početnoj (`Hero`, `SeriesCard`); specijali (`S1`…) kao posebna sekcija; filler oznake; progres po epizodi; rezervni izvori metapodataka (animap, Jikan); ručno mapiranje pomeraja; komandna paleta; blur režim; zaštita AniList opisa serije (ostaje iza klika kao do sada).

## 2. Arhitektura

```
ani-cli meni epizoda ──► watchService.onMenu / downloads.onMenu ──► episodeLists (episode-lists.json)

renderer (Detalj / Pretraga)
   │ episodes:for-series({ title, aniListId?, mode, list? })
   ▼
main ipc ──► seriesEpisodes.forSeries
               ├─ lista: list (Pretraga) | episodeLists.get(title, mode) | 1..max (sintetička)
               ├─ aniListId: arg | anilist.getForTitle(title)
               ├─ ani.zip: episodeMeta.get(aniListId)   (keš cache/anizip/<id>.json)
               ├─ M: library.findByAniCliTitle(title).watchedEpisodes
               ├─ otkrivanja + metaOff: seriesPrefs.get(title)
               ├─ hideSpoilers: settings.get()
               └─ za svaku epizodu: episodeVisibility → redactEpisode (bela lista)
   ◄── { episodes: [...očišćeno], source, meta }

   │ episodes:thumb({ ...args, episode })
   ▼
main ──► ponovo izračuna vidljivost ── hidden? ──► null (bez fetch-a)
                                     └─ inače ──► cache/anizip/thumbs/<id>-<n>.jpg ili fetch → data: URL

   │ episodes:reveal(args, { episode } | { all: true } | { reset: true })
   ▼
main ──► seriesPrefs.set(title, { reveal }) ──► vraća novu forSeries listu
```

Renderer ponovo traži listu na `EVENTS.libraryChanged` (M se pomera), posle `settings:update` koji menja `hideSpoilers`, i posle `episodes:reveal` (koristi vraćenu listu).

## 3. Komponente

### 3.1 `src/shared/spoilers.js` (novo, čisto)
- `watchedMax(watched)` → najveći broj iz niza (0 za prazan; decimale se poštuju, npr. 12.5).
- `episodeVisibility(n, { enabled, watchedMax, revealAll, revealed })` → `'full' | 'preview' | 'hidden'`:
  - `!enabled` ili `revealAll` ili `revealed` sadrži `n` ili `n ≤ watchedMax` → `'full'`;
  - `watchedMax < n ≤ watchedMax + 1` → `'preview'`;
  - inače `'hidden'`.
  - `n` je broj (`Number(label)`); nečitljiv broj → `'hidden'`.
- `redactEpisode(base, meta, visibility)` → nov objekat sa **belom listom**:
  - uvek: `number` (string iz liste), `runtime` (broj minuta ili `null`), `visibility`;
  - `preview`: + `title`, `hasThumb` (boolean);
  - `full`: + `title`, `hasThumb`, `overview`;
  - `hidden`: ništa više. Nikad `{...meta}`.
  - URL slike **nikad** ne ide u renderer (ni za vidljive): renderer dobija `hasThumb` i traži sliku preko `episodes:thumb`.

### 3.2 `src/shared/episodeMap.js` (novo, čisto)
- `metaKey(label)` → `"n"` za ceo broj `n ≥ 1`, inače `null` („0”, „12.5”, specijali nemaju metapodatke).
- `metaReliability(list, anizip)` → `'ok'` ako je broj celih epizoda `≥ 1` u listi `≤ anizip.episodeCount`, inače `'unreliable'`. Sintetička lista se ne proverava (`'ok'`).
- `pickTitle(titles, language)` → `en` → `x-jat` → prvi neprazan; `language` je jezik aplikacije (srpskog nema, isti redosled).

### 3.3 `src/main/episodeMeta.js` (novo)
- `createEpisodeMeta({ cacheDir, fetchImpl = fetch, now = Date.now })` → `{ get(aniListId, { airing }), thumb(aniListId, key) }`.
- `get`: `GET https://api.ani.zip/mappings?anilist_id=<id>`, timeout 15 s, deljeno obećanje po id-ju (nema paralelnih istih poziva).
  - Čuva samo: `episodeCount`, `episodes[key] = { titles, image, overview, runtime }` za ključeve glavnih epizoda (bez `S…`), `fetchedAt`.
  - Rok: 12 h ako je `airing` (AniList `status` u `RELEASING`/`NOT_YET_RELEASED`), inače 7 dana.
  - 404 → zapis „nije nađeno” (`missing: true`) 7 dana. Mreža/timeout/drugi status → zastareli keš ako postoji, inače `null`. Neispravan JSON → `null` (ne kvari keš).
- `thumb(aniListId, key)`: čita `thumbs/<id>-<key>.jpg` (+ tip), inače preuzima `image` iz keša (timeout 15 s, samo `https:`, najviše 2 MB, tip `image/*`), upisuje i vraća `data:` URL. Greška → `null`. Pozivalac (3.5) je već proverio vidljivost.

### 3.4 `src/main/episodeLists.js` (novo)
- `createEpisodeLists(file)` → `{ get(title, mode), set(title, mode, list) }`, `episode-lists.json`: `{ version: 1, series: { [key]: { sub?: { episodes, at }, dub?: {...} } } }`, ključ isti kao `seriesPrefs` (`normalizeTitle`, mala slova).
- `set` čuva samo nizove stringova (trim, bez praznih), upisuje samo kad se lista promenila.
- **Upis:** `watchService.spawn.onMenu` kad je `menuKind(prompt) === 'episode'` (i kad je odgovoreno automatski): naslov = `animeLineTitle(entry.animeLine)` normalizovan, ili `params.anime`; režim = `params.mode ?? settings.mode`. Isto u `downloads.js` (`item.aniCliTitle`, `item.mode`). Greška upisa se loguje i ne prekida ani-cli tok.

### 3.5 `src/main/seriesEpisodes.js` (novo) + IPC
- `createSeriesEpisodes({ library, seriesPrefs, settings, anilist, episodeMeta, episodeLists })`:
  - `forSeries({ title, aniListId = null, mode = null, list = null })` → `{ episodes, source, meta }`:
    - `source`: `'menu'` (prosleđena `list`), `'ani-cli'` (keš liste za režim `mode ?? prefs.resolve`), `'synthetic'` (`1..max(totalEpisodes, odgledano, 1)` kao danas);
    - `meta`: `'off'` (`metaOff`), `'none'` (nema id-ja ili ani.zip), `'unreliable'` (3.2), `'ok'`;
    - kad `meta !== 'ok'`, svaka epizoda je `{ number, runtime: null, visibility }` (vidljivost se ipak računa, zbog „Prikaži” doslednosti).
  - `thumb({ ...args, episode })` (`args` = isti argumenti kao `forSeries`, jer lista utiče na pouzdanost) → ponovo računa `forSeries` i uzima tu epizodu; `hidden` ili `meta !== 'ok'` → `null` bez ikakvog fetch-a.
  - `reveal(args, action)`, `action` = `{ episode }` | `{ all: true }` | `{ reset: true }` → `seriesPrefs.set(args.title, { reveal })`, vraća `forSeries(args)`.
- `seriesPrefs.get/set` dobija `reveal: { all: boolean, episodes: string[] }` i `metaOff: boolean` (sanitizovano; prazno se ne upisuje).
- `settings`: `hideSpoilers: true`, `episodeView: 'numbers' | 'list'` (podrazumevano `'numbers'`).
- IPC: `episodes:for-series`, `episodes:thumb`, `episodes:reveal`; `series-prefs:set` prihvata i `metaOff`. Preload: `window.animedesk.episodes.{forSeries, thumb, reveal}`.

### 3.6 Renderer
- **`useSeriesEpisodes({ title, aniListId, mode, list })`** (hook): poziva `forSeries`, osvežava na `libraryChanged` i na promenu `hideSpoilers`; vraća `{ series, reveal }`.
- **`EpisodePicker.jsx`**: opcioni `series`, `view`, `onView`, `onReveal`. Prekidač **Brojevi / Lista** (`role="group"`, `aria-pressed`) samo kad je `series?.meta === 'ok'`. Pilule bez izmena (bez naslova u `title`/`aria-label`). Grupe od 100 i „idi na epizodu” važe u oba prikaza; traka radnji ostaje.
- **`EpisodeRow.jsx`** (novo):
  - `full`: sličica (ili poster serije), „Epizoda N · Naslov”, trajanje, ✓ ako je odgledana, dugme „Opis” koje razvija `overview` (samo ako postoji);
  - `preview`: isto bez „Opis”;
  - `hidden`: poster serije, „Epizoda N”, trajanje, dugme „Prikaži” (`onReveal(number)`);
  - odgledana: prigušena sličica, puna na hover; klik na red = `onToggle(number)` kao pilula; „Prikaži”/„Opis” zaustavljaju propagaciju.
  - Sličica: `IntersectionObserver` → `episodes.thumb` tek kad red uđe u vidno polje; dok se ne učita/ako je `null` → poster serije. `alt=""`.
- **`AnimeDetail.jsx`**: lista iz `forSeries` (bez `list`); ispod liste red „Spojleri” (samo kad je `meta` `'ok'` ili `'unreliable'`): „Prikaži sve epizode ove serije” / „Ponovo sakrij otkrivene”, „Isključi metapodatke za ovu seriju” (prekidač `metaOff`); za `'unreliable'` prigušena napomena. Beleške i „odgledano” rade sa brojem epizode kao do sada.
- **`SearchPage.jsx`**: prosleđuje `list = menu.lines` i naslov izabranog animea.
- **`SettingsPage.jsx`**: odeljak „Spojleri” sa poljem „Skrivaj spojlere (naslove, sličice i opise epizoda posle sledeće)”.
- i18n: novi ključevi u `sr.json` i `en.json`; CSS samo preko tokena (`styles.test.js`).

## 4. Tok podataka i greške
- ani.zip nedostupan / bez serije / bez `aniListId` → `meta: 'none'`, prekidač se ne prikazuje, pilule kao u 0.6.5.
- Sličica ne uspe → poster serije; nema ponovnog pokušaja u istoj sesiji stranice.
- Biblioteka bez unosa za seriju (Pretraga, nova serija) → M = 0 (vidi se samo epizoda 1).
- Lista se menja tokom gledanja (nova odgledana epizoda) → `libraryChanged` → nova lista; epizoda koja je bila `preview` postaje `full`, sledeća postaje `preview`.
- Isključen `hideSpoilers` → sve `full`; uključen ponovo → otkrivanja po seriji/epizodi ostaju (nisu obrisana).
- Upis `episode-lists.json` ne uspe → log, ani-cli tok ide dalje.

### Ručna provera (prava aplikacija, Playwright `_electron`, izolovan profil, snimci ekrana koji se stvarno pogledaju)
1. Frieren u watchlist-i, odgledano 1–3, prikaz Lista na detalju: 1–3 pune, 4 bez „Opis”, 5+ poster + „Prikaži”.
2. „Prikaži” na 6 → 6 puna; restart aplikacije → 6 i dalje otkrivena.
3. „Prikaži sve” → sve pune; „Ponovo sakrij otkrivene” → stanje iz 1.
4. Podešavanja → isključi „Skrivaj spojlere” → sve pune; uključi → stanje iz 1.
5. Pretraga (pravi ani-cli meni) → prikaz Lista sa istim pravilom.
6. Bez mreže (ili lažan `aniListId`) → pilule, bez prekidača i bez greške.
7. Folder `cache/anizip/thumbs` nema sličice skrivenih epizoda.
